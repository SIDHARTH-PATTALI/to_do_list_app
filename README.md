
# AI-Made To-Do (Streamlit)

A minimal to-do list app generated by ChatGPT using Streamlit.

## Features
- Add, edit, delete tasks
- Mark tasks done/undone
- Priorities, optional due dates
- Filter and sort
- Saves to `todos.json` on the server

## Quick Deploy (Hugging Face Spaces)
1. Create a new Space → **Streamlit**.
2. Upload `app.py` and `requirements.txt` (and optionally this README).
3. The Space will build and give you a public URL like: `https://huggingface.co/spaces/<your-username>/ai-todo`

## Quick Deploy (Streamlit Community Cloud)
1. Create a new app from this folder in a GitHub repo.
2. Point Streamlit Cloud to `app.py`.
3. Get your public URL like: `https://<your-app-name>.streamlit.app`

Once deployed, paste the resulting URL into your Google Form.
